# Notes de frais : Nordia Systems

Toute dépense professionnelle engagée par un salarié en déplacement doit
être déclarée via l'outil Spendflow, dans les 30 jours suivant la dépense.

## Plafonds

Le plafond de remboursement pour les repas est de 25€ par jour en
déplacement professionnel. Un justificatif (facture ou ticket) est
obligatoire pour toute dépense supérieure à 10€ ; en dessous de ce
montant, une simple déclaration suffit.

## Transport

Les trajets en train se font en 2nde classe par défaut. La 1ère classe
n'est autorisée que pour les trajets dont la durée dépasse 3 heures.

## Remboursement

Une fois la note de frais validée par le manager, le remboursement est
versé sous 10 jours ouvrés, directement sur le compte bancaire déclaré
dans Spendflow.

## Hébergement

Pour les déplacements nécessitant une nuitée, le plafond hôtel est de 120€
par nuit en France métropolitaine, et de 150€ à l'international.
