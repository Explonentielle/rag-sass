# Sécurité informatique : Nordia Systems

L'authentification à deux facteurs (2FA) est obligatoire pour l'ensemble
des comptes professionnels : messagerie, outils internes, et accès au
code source.

## Mots de passe

Les mots de passe doivent être renouvelés tous les 90 jours. Un mot de
passe oublié peut être réinitialisé via le portail IT, disponible 24h/24.

## Règles d'usage

L'utilisation de clés USB personnelles sur le matériel de l'entreprise est
strictement interdite. Le VPN de l'entreprise est obligatoire pour toute
connexion aux outils internes depuis l'extérieur du bureau, y compris en
télétravail.

## Signalement d'incident

Tout incident de sécurité suspecté (phishing, perte d'appareil, accès
suspect) doit être signalé sous 24h à l'adresse
securite@nordia-systems.example. Une astreinte sécurité est disponible le
week-end pour les incidents critiques.

## Formation

Une formation sécurité informatique est obligatoire une fois par an pour
tous les salariés, dispensée en ligne via la plateforme de formation
interne.
